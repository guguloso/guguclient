# Gugu Client v1.1.0 - What's new?

The 1.1.0 cycle was all about performance, privacy, and rewriting the launcher from scratch into a native **Rust + Tauri 2** executable.

## Added

### Native Rust + Tauri 2 Runtime
- Gugu Client **no longer requires Electron or Node.js** at runtime
- Ships as a single portable **~23 MB** `GuguClient.exe` rendered via WebView2, using around **50 MB of RAM**
- All **380 / 380** `window.api` IPC channels are served natively in async Rust on Tokio (accounts, instances, FastFlags, mods, Discord RPC, macros, captures, chat, and 3D avatar rendering)

### Multi-Language Support (Auto-Detected + Settings)
- Automatically detects your Windows language/region (`GetUserDefaultLocaleName`) and translates the launcher into **Português (Brasil)**, **English**, or **Español**
- Added a **Language** selector under **Settings → Appearance** (`System default`, `Português (Brasil)`, `English`, `Español`)

### Native Rust Setup Installer (`GuguClient-Setup-windows-x64.exe`)
- Built a clean, fast Windows installer and uninstaller entirely in Rust (`setup/`), with dark UI, automatic OS language detection, Desktop & Start Menu shortcuts, Windows Apps & Features registration, and `--silent` / `--uninstall` support

## Changed

### Folder Layout & Automatic Migration
- Moved launcher storage to `%USERPROFILE%\.gugu-for-roblox\` and captures to `%USERPROFILE%\Videos\Gugu\`
- Existing `.lunar-for-roblox` data and `Videos\Lunar` captures migrate automatically on first launch

### Privacy & UI Cleanup
- Disabled telemetry/analytics collection completely in the Rust backend and removed the **Privacy / Allow Analytics Collection** toggle from Settings

## Fixed

### Live Friends & Presence
- Fixed the **Friends** sidebar staying stale until restarting the launcher
  * Presence polling now checks **all** friends (including offline) every **15 seconds** in the foreground
  * Restoring or focusing the window immediately refreshes stale friends and presence data
  * Adding, accepting, or removing friends triggers an immediate refresh
- Cached friend avatars automatically update when users change their Roblox headshot

### Text Encoding & Layout
- Fixed **89** double-encoded UTF-8 (mojibake) text sequences across the UI (`•`, `…`, `—`, `·`, `×`, and emojis)
- Fixed chat scrolling and dialog heights so the 3D avatar viewer fits cleanly at `1400×800`

## Download

Download **`GuguClient-Setup-windows-x64.exe`** below and run it to install or update Gugu Client in seconds.

> The installer and launcher contain zero personal data, cookies, or account credentials — all Roblox sessions stay encrypted locally on your own machine (`%USERPROFILE%\.gugu-for-roblox\auth.json`).
