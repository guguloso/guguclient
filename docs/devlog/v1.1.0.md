# Gugu Client v1.1.0 — Native Rust Edition

Gugu Client is a fork of **Lunar for Roblox**, rebuilt with a native **Rust + Tauri 2** backend and actively maintained with constant updates. No Electron, no bundled Chromium, and no Node.js runtime — everything ships in a single `GuguClient.exe` (~23 MB) rendered via Windows WebView2.

---

## Devlog — What Changed in v1.1.0

### 1. Native Rust + Tauri 2 Port
- Replaced the Electron main process, native C/C++ addons, and NSIS wrapper with a single async Rust binary (`src-tauri/`) running on Tokio.
- All **380 / 380** frontend `window.api` IPC channels are served natively by Rust (`auth`, `friends`, `social`, `chat`, `avatar`, `avatar_render`, `launch`, `versions`, `instances`, `macros`, `captures`, `discord_rpc`, `updater`, and more).
- Reduced launcher memory footprint to around **50 MB RAM** with instant startup from cached snapshots.

### 2. Real-Time Friends & Presence
- Fixed an issue where the **Friends** sidebar appeared stale until restarting the launcher:
  - Presence polling now checks **all** friends (both online and offline) on every cycle every **15 seconds** in the foreground instead of skipping offline users for multiple cycles.
  - Restoring or focusing the window immediately refreshes stale social/presence data, and adding/removing/accepting friends triggers an instant refresh.
  - Cached friend avatars automatically refresh in the background when users update their Roblox profile picture.

### 3. Privacy & Cleanliness
- Disabled telemetry/analytics collection at both the backend (`analytics:track` and `AppState::track` are no-ops, `allow-analytics-collection` defaults to `false`, registry opt-out marker sync removed) and the Settings UI (**Privacy / Allow Analytics Collection** section removed).

### 4. UI & Text Fixes
- Fixed **89** double-encoded UTF-8 (mojibake) text sequences across the UI bundle so bullets (`•`), ellipses (`…`), dashes (`—`), symbols, and emojis render cleanly everywhere.
- Refined dialog scrolling and profile layout so the 3D avatar viewer and item lists fit cleanly at `1400×800`.

### 5. Clean Storage & Migration
- Launcher data now lives under `%USERPROFILE%\.gugu-for-roblox\` and captures under `%USERPROFILE%\Videos\Gugu\`.
- Existing `.lunar-for-roblox` folders and `Videos\Lunar` captures are automatically migrated on first launch.

## Downloads & Integrity

| File | Description |
| --- | --- |
| `GuguClient.exe` | Standalone portable executable (Windows 10/11 x64, WebView2) |
| `SHA256SUMS.txt` | SHA-256 checksum to verify your download |

Verify the checksum in PowerShell after downloading:

```powershell
Get-FileHash .\GuguClient.exe -Algorithm SHA256
```

> **Note:** `GuguClient.exe` contains zero personal data, cookies, or account credentials — all Roblox sessions stay encrypted locally on your own machine using Windows DPAPI (`%USERPROFILE%\.gugu-for-roblox\auth.json`).
